- 재시도: 구매 한도 최초 생성 충돌만 새 트랜잭션으로 1회. 조건부 UPDATE의 정책 거절은 재시도하지 않음

- 동시 사용자: 8·32·64명, 각각 3회 반복. 매 실행 JVM·DB 재시작
- 환경: M1 Pro / 32 GiB, Docker 2 CPU / 3.83 GiB, JDK 25.0.2, PostgreSQL 18.6
- 도구: Docker Engine 29.9.2, k6 2.3.0
- 설정: JVM 512 MiB, DB 커넥션 16개, READ COMMITTED, 잠금 제한 5초

않는다.
